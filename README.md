# Модуль 09. Домашнее задание: Task Manager на Golang

Самостоятельная работа студентов (СРС / Домашнее задание) по дисциплине «Разработка веб-сервисов» (CSE5032).  
Кафедра Программной инженерии, Институт Автоматики и информационных технологий.

---

## 🎯 Цель работы
Закрепить навыки разработки на Go:
- Проектирование собственного интерфейса `TaskStorage`;
- Реализация контракта интерфейса с помощью структуры `InMemoryTaskStorage`;
- Работа со словарем `map[int]Task` для быстрого доступа по ID;
- Обработка ошибок в стиле Go через встроенный тип `error` и `fmt.Errorf`;
- Формирование аналитических показателей (процент выполнения задач).
